# MollyStudio

Редактор GUI, пиксельной графики и префиксов для Minecraft Java Edition.

## Скачать

**[Последняя версия для Windows 10/11 x64](https://github.com/Nagivka/MollyStudio-Releases/releases/latest)**

В разделе Assets скачайте файл `MollyStudio-…-x64-portable.exe`. Установка и дополнительные компоненты не нужны. При первом запуске portable распаковывает приложение; это может занять немного времени.

Сохраните проекты в `.mlst` перед переходом на новую версию. Файл `.sha256` рядом с EXE позволяет проверить целостность загрузки:

```powershell
Get-FileHash .\MollyStudio-1.4.0.0-x64-portable.exe -Algorithm SHA256
```
